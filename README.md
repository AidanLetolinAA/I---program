# I---program

Небольшой учебный репозиторий: внутри лежит простая Python-программа, на
которой можно тренироваться. Она показывает:

* как описывать функции и работать с аргументами;
* как использовать циклы и простую арифметику;
* как запускать скрипт из командной строки.

## Как запустить
1. Убедитесь, что установлен Python 3.10+.
2. Откройте терминал и перейдите в папку проекта: `cd I---program`.
3. Выполните команду:
   ```bash
   python main.py --name "Ваше имя" --limit 10
   ```
   Параметры не обязательны: без них программа поздоровается с "друг" и
   посчитает сумму от 1 до 5.

## Что попробовать
* Измените аргументы `--name`, `--limit`, `--excited` и посмотрите, как
  меняется вывод.
* Откройте `main.py`, измените текст приветствия или логику суммирования
  (например, сложите только четные числа) и перезапустите файл.
* Попробуйте добавить новую функцию, которая будет находить минимальное
  и максимальное числа в списке, и выведите результат в консоль.

Если что-то непонятно — спрашивайте, помогу разобраться!
